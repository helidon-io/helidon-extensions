# io.<wbr>helidon.<wbr>extensions.<wbr>langchain4j.<wbr>McpRoot<wbr>Config

## Description

An MCP root made available to the server through the legacy MCP protocol.

## Configuration options

| Key | Type | Description |
| --- | --- | --- |
| `uri` | `URI` | Required URI identifying the root. |
| `name` | `String` | Optional human-readable name. The URI is advertised as the name when absent. |
